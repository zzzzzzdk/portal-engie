# 表单设计器接入联动实施清单

## 目标

将表单容器接入现有系统组件联动体系，使表单容器既能作为事件发送方，也能作为事件接收方，并与表单内部字段联动协同运行。

本方案不新增表单专属事件总线，统一复用现有 `WidgetEventBus`、`eventOutputs`、`eventInputs`、参数映射、防抖、定向目标和链路深度保护能力。

## 总体原则

- 系统组件之间的联动统一走 `WidgetEventBus`。
- 表单字段内部显隐、禁用、必填、选项依赖继续走 Native Form 自身联动能力。
- `NativeFormWidget` 负责在系统组件事件和表单运行时之间做适配。
- 外部事件回填表单后，默认触发表单内部联动，但默认不继续向外广播 `form.change`，避免循环联动。
- 配置 UI 复用现有 `EventLinkageConfig`，只增强表单字段识别、动作说明和字段校验。

## 实施清单

### 1. 类型与能力声明

涉及文件：

- `src/types/index.ts`
- `src/types/widget-event.ts`
- `src/utils/widgetEventCapabilities.ts`
- `src/native-form/shared/defaults.ts`

实施内容：

- 为 `nativeForm` 补齐输出事件：`form.change`、`form.submit`、`form.reset`、`field.change`、`field.click`。
- 为 `nativeForm` 增加输入动作：`setValue`、`clearValue`、`reset`、`setParams`、`setParamsAndReload`、`clearParams`。
- 增加表单联动运行时配置类型 `NativeFormLinkageRuntimeConfig`。
- 在 `NativeFormWidgetConfig` 中增加 `linkageRuntime?: NativeFormLinkageRuntimeConfig`。
- 在默认配置中补齐 `linkageRuntime` 默认值。

建议默认值：

```ts
linkageRuntime: {
  emitChangeOnExternalSetValue: false,
  runInternalLinkageOnExternalSetValue: true,
  validateOnExternalSetValue: false,
  reloadOptionsOnParamsChange: true,
  defaultChangeDebounce: 300,
}
```

验收标准：

- 联动配置中可选择 `nativeForm` 作为发送方和接收方。
- `nativeForm` 的输出事件和输入动作能在配置弹窗中展示。
- 默认配置兼容旧表单，不破坏已有表单数据。

### 2. Renderer 可控化

涉及文件：

- `src/native-form/runtime/native-form-renderer.tsx`

实施内容：

- 支持外部传入 AntD `FormInstance`。
- 抽出统一的表单值变更处理逻辑，避免用户输入和外部回填走两套逻辑。
- 增加 `runtimeParams` 入参，用于系统组件事件传入的运行时参数。
- 增加 `onFormReset` 回调。
- 增加 `onFieldEvent` 回调，用于容器内字段级事件透出。
- 保持未传入外部 `form` 时的原有行为。

建议接口：

```ts
interface NativeFormRendererProps {
  config: NativeFormWidgetConfig
  widgetId?: string
  form?: FormInstance
  runtimeParams?: Record<string, any>
  onFormChange?: (
    changedValues: Record<string, any>,
    values: Record<string, any>,
    meta?: NativeFormChangeMeta,
  ) => void
  onFormSubmit?: (
    values: Record<string, any>,
    response?: any,
  ) => void
  onFormReset?: (
    values: Record<string, any>,
    previousValues?: Record<string, any>,
  ) => void
  onFieldEvent?: (
    eventName: 'field.change' | 'field.click',
    payload: NativeFormFieldEventPayload,
  ) => void
}
```

验收标准：

- `NativeFormWidget` 可以通过外部 `form` 控制 `NativeFormRenderer`。
- 原有表单预览、提交、字段变化能力不回退。
- 外部回填时可以拿到最新 `values`。

### 3. NativeFormWidget 接入事件输入

涉及文件：

- `src/components/widgets/NativeFormWidget.tsx`
- `src/hooks/useWidgetEventInputs.ts`
- `src/hooks/useWidgetEventEmitter.ts`

实施内容：

- 在 `NativeFormWidget` 中创建并传入 AntD `form`。
- 接入 `useWidgetEventInputs(widget, handlers)`。
- 实现 `setValue`：将映射后的参数写入表单字段。
- 实现 `clearValue`：清空指定字段；未指定字段时清空全部可控字段。
- 实现 `reset`：恢复表单初始值。
- 实现 `setParams`：写入表单运行时参数。
- 实现 `setParamsAndReload`：写入运行时参数并触发依赖刷新。
- 实现 `clearParams`：清空运行时参数。
- 外部写值后，根据 `linkageRuntime` 决定是否触发内部联动、校验和外部广播。

动作语义：

```ts
setValue(params)
// params 的 key 为表单字段名，value 为字段值。

clearValue({ fields })
// fields 存在时只清空指定字段，否则清空全部可控字段。

reset()
// 恢复 initialValues。

setParams(params)
// 更新 runtimeParams，不直接写入字段。

setParamsAndReload(params)
// 更新 runtimeParams，并触发远程选项或依赖数据刷新。

clearParams()
// 清空 runtimeParams。
```

验收标准：

- 数据表格 `table.rowClick` 可以回填表单多个字段。
- 指标卡 `card.click` 可以回填表单单个字段。
- 外部 `reset` 可以恢复表单初始值。
- 外部 `clearValue` 可以清空指定字段。
- 外部回填默认不继续发送 `form.change`。

### 4. 输出事件补齐

涉及文件：

- `src/components/widgets/NativeFormWidget.tsx`
- `src/native-form/runtime/native-form-renderer.tsx`
- `src/utils/widgetEventFieldSuggestions.ts`

实施内容：

- 保留并规范 `form.change` 输出。
- 保留并规范 `form.submit` 输出。
- 补齐 `form.reset` 输出。
- 补齐容器内字段级 `field.change` 输出。
- 补齐容器内字段级 `field.click` 输出。
- `form.change` payload 增加 `changedValues`、`changedField`、`changedValue`、`fieldConfig`。
- `form.submit` payload 增加 `submitConfig`。

建议 payload：

```ts
// form.change
{
  values: Record<string, any>,
  changedValues: Record<string, any>,
  changedField?: string,
  changedValue?: any,
  fieldConfig?: NativeFormNode,
}

// form.submit
{
  values: Record<string, any>,
  response?: any,
  submitConfig?: NativeFormSubmitConfig,
}

// form.reset
{
  values: Record<string, any>,
  previousValues?: Record<string, any>,
}

// field.change
{
  field: string,
  value: any,
  values: Record<string, any>,
  fieldConfig?: NativeFormNode,
}
```

验收标准：

- 表单提交可以驱动表格、图表执行 `setParamsAndReload`。
- 表单变化可以驱动外部组件执行 `setParams` 或 `setParamsAndReload`。
- 表单重置可以驱动外部组件执行 `clearParams` 或 `clearValue`。
- 字段级事件可以被其他系统组件监听。

### 5. 配置 UI 增强

涉及文件：

- `src/components/ConfigDialog/configs/EventLinkageConfig.tsx`
- `src/utils/widgetEventFieldSuggestions.ts`
- `src/utils/widgetEventCanvas.ts`
- `src/components/ConfigDialog/index.tsx`

实施内容：

- 表单容器作为来源组件时，路径建议展示表单字段。
- 表单容器作为目标组件时，目标参数建议展示表单字段名。
- `setValue` 动作下，目标参数占位改为“表单字段名”。
- `clearValue` 动作下，支持配置 `fields`。
- `setParams` 动作下，目标参数占位改为“运行时参数名”。
- 为表单动作增加中文说明。
- 保存时校验目标字段是否存在于 `formSchema`。
- 监听 `form.change` 且未设置防抖时，提示建议设置 300ms 防抖。

来源路径建议示例：

```text
payload.values.plateNo
payload.changedValues.plateNo
payload.changedField
payload.changedValue
payload.fieldConfig.label
meta.sourceTitle
message.timestamp
```

目标参数建议示例：

```text
plateNo
personName
idCard
startTime
endTime
regionCode
```

验收标准：

- 用户配置表单联动时可以直接选择字段路径。
- 用户配置 `setValue` 时可以直接选择目标字段。
- 保存不存在的目标字段时有明确提示。
- 高频 `form.change` 配置有防抖建议。

### 6. 表单内部联动协同

涉及文件：

- `src/native-form/runtime/native-form-renderer.tsx`
- `src/native-form/shared/field-helpers.ts`
- `src/components/widgets/NativeFormWidget.tsx`

实施内容：

- 用户输入字段时：触发表单内部联动，并按 `eventOutputs` 发送系统组件事件。
- 外部 `setValue` 时：默认触发表单内部联动，不默认发送系统组件事件。
- 外部 `reset` 时：触发表单内部联动，并按配置决定是否发送 `form.reset`。
- 外部 `setParamsAndReload` 时：刷新依赖 `runtimeParams` 的远程选项或内部数据。
- 字段条件判断时可以读取最新表单值。
- 远程选项加载时可以读取 `runtimeParams`。

验收标准：

- 外部回填字段后，相关字段的显隐、禁用、必填状态同步刷新。
- 外部参数变化后，依赖该参数的远程选项可以刷新。
- 用户输入和外部回填不会造成状态不一致。

### 7. 远程选项与运行时参数

涉及文件：

- `src/native-form/runtime/native-form-renderer.tsx`
- `src/native-form/shared/field-helpers.ts`
- `src/utils/widgetApi.ts`

实施内容：

- 远程选项请求参数支持读取 `formValues`。
- 远程选项请求参数支持读取 `runtimeParams`。
- `setParamsAndReload` 后触发依赖运行时参数的远程选项刷新。
- 请求失败时保留原选项或回退为空数组，并记录错误。

建议路径：

```text
formValues.keyword
formValues.regionCode
runtimeParams.regionCode
runtimeParams.parentId
```

验收标准：

- 外部组件选择区域后，表单中的街道、单位等下拉选项可以重新加载。
- 远程选项刷新失败不会导致整个表单崩溃。

### 8. 联动治理与循环保护

涉及文件：

- `src/utils/widgetEventBus.ts`
- `src/utils/widgetEventLogger.ts`
- `src/components/ConfigDialog/configs/EventLinkageConfig.tsx`
- `src/components/widgets/NativeFormWidget.tsx`

实施内容：

- 保留现有 `WIDGET_EVENT_MAX_DEPTH` 链路深度限制。
- 外部 `setValue` 默认不广播 `form.change`。
- `form.change` 高频场景建议使用防抖。
- 配置层检测明显闭环并给出 warning。
- 日志保留 `traceId`、`parentId`、`depth`。
- 映射路径不存在时记录 warning。
- 目标字段不存在时运行时忽略，并记录 warning。

典型需要避免的循环：

```text
表单 form.change
  -> 表格 setParamsAndReload
  -> 表格 data.loaded
  -> 表单 setValue
  -> 表单 form.change
```

验收标准：

- 上述闭环默认不会无限触发。
- 超过最大链路深度时事件被阻断并记录原因。
- 用户能通过事件日志定位联动链路。

## 推荐落地顺序

1. 先完成类型、能力声明和默认配置。
2. 再完成 `NativeFormRenderer` 可控化。
3. 再完成 `NativeFormWidget` 接收事件动作。
4. 再补齐表单输出事件。
5. 再增强配置 UI 和字段路径建议。
6. 再处理远程选项与运行时参数。
7. 最后补充循环保护、日志和测试场景。

## 最终验收标准

完成后应稳定支持以下链路：

- 表格行点击 -> 表单回填。
- 指标卡点击 -> 表单字段设置。
- 表单提交 -> 表格刷新。
- 表单字段变化 -> 图表参数更新。
- 外部重置按钮 -> 表单 reset -> 表格清空参数。
- 卡片点击 -> 表单字段设置 -> 用户提交 -> 多组件刷新。

同时满足：

- 不新增第二套事件总线。
- 原有系统组件联动不受影响。
- 原有 Native Form 设计器不受影响。
- 外部回填不会默认造成循环广播。
- 表单字段映射配置可视化、可校验、可调试。
