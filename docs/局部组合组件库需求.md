# 根据用户已经在工作台设置的组件，保存成新的组件

需要在各组件右上角标题按钮区域添加一个保存按钮，通过保存按钮将当前状态的组件保存成新组件，保留当前设置的组件配置和数据等。

1. 可以保存单个组件，将用户设置好的某个组件，保存成新组件。
2. 可以保存分组，分组内可能包含多个组件。
3. 在左侧组件库/AI面板，添加新的tab，用来保存显示当前已经保存的新组件。
4. 通过点击或者拖拽，将新保存的组合组件添加到工作台，拖拽方式同组件库现有逻辑和功能。
5. 如果工作台当前正在编辑的组件，没有完成编辑，没有填满必填项，不允许保存新组件
6. 如果是空分组，不允许保存成新组件。
7. 如果当前编辑的组件，和原有组件库新增的组件模板数据和配置，没有任何改动的话，不用保存成新组件，没有意义。
8. 保存新组件需要支持设置分类和自定义名称，
9. 分类管理通过左侧面板进行管理，新增删除分类。
10. 将新增按钮改的样子小一点，点击按钮，出来个新增分类的小弹窗，填入分类名称，确认后再进行新建
