# 表单联动手动测试清单

测试目标：验证查询筛选、自定义表单、原生字段、搜索、表格、图表、指标卡之间的事件联动是否好用、稳定、易配置。

建议先准备一个测试工作台，添加这些组件：

- 查询筛选组件
- 搜索组件
- 数据表格组件
- 图表组件
- 指标卡组件
- 自定义表单组件
- 原生字段组件
- 可选：悬浮模块

## 一、基础准备

| 编号 | 测试项 | 操作 | 预期结果 |
| --- | --- | --- | --- |
| 1.1 | 添加组件 | 在画布添加查询筛选、搜索、表格、图表、指标卡、自定义表单、原生字段 | 所有组件正常显示 |
| 1.2 | 打开联动配置 | 打开任一组件配置弹窗，进入“联动”Tab | 能看到当前组件能力、当前画布组件列表、发送事件、监听事件、最近事件 |
| 1.3 | 组件列表检查 | 查看“当前画布可选组件” | 只展示当前画布已有组件 |
| 1.4 | 问号提示 | 鼠标悬浮“Payload 映射”“参数映射”旁边问号 | 显示解释说明 |
| 1.5 | 保存配置 | 配置一条联动后保存，再重新打开配置弹窗 | 联动配置不丢失 |

## 建议测试顺序

先测最核心 8 条：

1. 查询筛选 -> 搜索。
2. 查询筛选 -> 表格。
3. 查询筛选重置 -> 搜索清空 + 表格清参。
4. 搜索 -> 表格。
5. 搜索 -> 图表。
6. 自定义表单 -> 搜索 + 表格。
7. 原生字段 -> 搜索。
8. 表格行点击 -> 搜索 + 指标卡。

然后测高风险配置：

1. 参数映射改名。
2. `literal:` 固定值。
3. `merge/replace/clearThenMerge`。
4. 防抖。
5. 禁用发送/监听。
6. 路径不存在。
7. 最近事件日志。
8. 循环保护。

最后测兼容性：

1. 不配置联动时旧逻辑是否还在。
2. 配置内部联动后是否不再误弹旧提示。
3. API 提交和 Wujie eventRoutes 是否不受影响。
