## 三、操作题参考答案

### 第1题：添加并配置小部件的步骤

1. 点击顶部工具栏的"添加小部件"下拉菜单
2. 选择"数据统计"类型
3. 小部件会自动添加到 Dashboard 中
4. 拖拽小部件顶部手柄，移动到页面右上角位置
5. 点击小部件右上角的"设置"图标
6. 在配置弹窗中将标题修改为"今日访问量"
7. 点击确定保存配置

### 第2题：Dashboard 空白页排查方向

- 检查用户是否已正常登录（Token 是否有效）
- 检查浏览器控制台是否有错误信息
- 检查网络请求是否正常（API 是否可达）
- 尝试清除浏览器本地存储后刷新
- 检查用户是否有 Dashboard 页面的访问权限
- 确认后端服务是否正常运行

## 四、简答题参考答案

### 小部件与浮动模块的区别

| 对比项 | 小部件（Widget） | 浮动模块（FloatingModule） |
|--------|------------------|---------------------------|
| **位置** | 固定在 Dashboard 网格中 | 可在屏幕任意位置浮动 |
| **布局** | 受12列网格约束 | 自由定位，可收起/展开 |
| **使用场景** | 数据展示、图表、统计卡片 | 在线客服、消息通知、辅助工具 |
| **交互方式** | 编辑模式下拖拽调整 | 随时可拖动、缩放 |

**使用场景举例：**

- **小部件**：适合展示固定的业务数据，如今日访问量、销售统计图表、待办事项列表等
- **浮动模块**：适合需要随时访问的辅助功能，如在线客服聊天窗口、系统通知、快捷工具等
