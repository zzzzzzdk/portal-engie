## 项目概述

该是一个基于 React + TypeScript + Vite 构建的企业级仪表盘应用，它允许用户通过拖拽和配置的方式创建个性化的数据展示面板。该应用采用了现代化的前端技术栈和优雅的用户界面设计，为企业提供灵活、高效的数据可视化解决方案。

## 技术栈

- **前端框架**: React
- **类型系统**: TypeScript
- **构建工具**: Vite
- **UI 组件库**: antd
- **状态管理**: Zustand
- **样式框架**: SCSS
- **动画库**: Framer Motion
- **图标库**: Lucide React
- **网格布局**: React Grid Layout

## 核心模块分析

### 1. 应用入口

App.tsx 是整个应用的入口点，主要负责：
- 渲染顶部导航栏，包含应用标题和操作按钮
- 提供"添加小部件"和"编辑模式"切换功能
- 集成 Dashboard 组件作为主要内容区域

### 2. 工作台组件

工作台组件是应用的核心组件，实现了：
- 使用 React Grid Layout 实现响应式网格布局
- 提供小部件的渲染和布局管理
- 支持拖拽和调整大小功能（仅在编辑模式下）
- 根据不同屏幕尺寸自适应布局
- 支持全屏模式（用来布局大图）和非全屏模式。

### 3. 状态管理 (useStore.ts)

使用 Zustand 实现全局状态管理，主要功能包括：
- 管理小部件列表和布局
- 控制编辑模式状态
- 提供添加、删除、更新小部件的方法
- 使用 localStorage 持久化状态

### 4. 小部件包装器 (WidgetWrapper.tsx)

为所有小部件提供统一的包装，包括：
- 统一的视觉样式和交互
- 右键上下文菜单（配置、刷新、删除）
- 编辑模式下的拖拽手柄
- 小部件配置对话框的触发

### 5. 配置对话框 (ConfigDialog.tsx)

提供小部件配置功能，支持：
- 修改小部件标题
- 设置数据刷新间隔
- 配置 API 端点
- 针对自定义表单小部件的表单字段构建器

### 6. 小部件组件 (widgets/)

包含 10 种不同类型的小部件，每种都有特定功能：

- **ClockWidget**: 显示当前时间和日期
- **StatsWidget**: 展示关键指标数据
- **ChartWidget**: 显示折线图等数据图表
- **LinkWidget**: 快速链接按钮
- **NewsWidget**: 新闻卡片展示
- **TopListWidget**: Top 10 列表展示
- **SearchWidget**: 搜索框
- **DataTableWidget**: 数据表格
- **CardGridWidget**: 卡片网格布局
- **CustomFormWidget**: 自定义表单，支持动态字段配置

## 数据类型定义

项目的类型定义在 `src/types/index.ts` 中，主要包括：
- **WidgetType**: 定义所有可用的小部件类型
- **WidgetConfig**: 小部件配置接口
- **Widget**: 小部件接口，包含位置、尺寸和配置信息
- **AppState**: 应用全局状态接口

## 主要功能特性

1. **可拖拽布局**: 用户可以在编辑模式下自由拖拽和调整小部件大小
2. **响应式设计**: 应用根据不同屏幕尺寸自动调整布局
3. **配置灵活**: 每个小部件都可以通过配置对话框进行个性化设置
4. **数据持久化**: 使用 localStorage 保存用户的布局和配置
5. **丰富的小部件**: 提供 10 种不同类型的小部件满足各种数据展示需求
6. **自定义表单构建器**: 支持动态创建表单字段，构建自定义表单

## 发布与预览

1. **发布**: 需要将组件及配置信息，发布到指定接口，让其存储。
2. **预览**: 如果只拿者配置信息，来到该系统，本系统需要根据配置信息，生成一个预览页面，并且保证各项功能正常。
