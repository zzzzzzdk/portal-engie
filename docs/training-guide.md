## 一、系统概述

### 1.1 系统介绍

Portal Engine 是一个**企业级可视化仪表盘平台**，用户可通过拖拽配置的方式创建个性化的数据展示面板。

**核心特性：**

- 12列响应式网格布局系统
- 支持拖拽配置小部件
- 浮动窗口支持（如在线客服、消息通知）
- 微应用集成（嵌入第三方系统）
- 主题切换与个性化配置
- 配置自动保存与持久化

## 二、登录与认证

### 2.1 登录流程

1. 打开系统首页，自动跳转到登录页面
2. 输入用户名和密码
3. 点击"登录"按钮
4. 登录成功后自动跳转到 Dashboard 页面

### 2.2 登录界面

登录页面包含以下元素：
- 用户名输入框
- 密码输入框
- 登录按钮

### 2.3 认证机制

- 系统采用 **Cookie Token** 认证方式
- Token 存储在名为 `YSTOKEN` 的 Cookie 中
- Token 过期后需重新登录

### 2.4 退出登录

1. 点击页面右上角的用户头像
2. 点击"退出登录"按钮
3. 系统清除登录状态并跳转到登录页

## 三、Dashboard 仪表盘操作

### 3.1 编辑模式 vs 预览模式

| 模式 | 特点 | 用途 |
|------|------|------|
| **编辑模式** | 可拖拽、调整大小、添加/删除小部件 | 配置仪表盘布局 |
| **预览模式** | 只读展示，不可编辑 | 正常使用和展示 |

**切换方式：** 点击顶部工具栏的"编辑/预览"切换按钮

### 3.2 网格布局系统

- 采用 **12列网格** 布局
- 每行可放置多个小部件
- 小部件最小宽度：1列
- 小部件最小高度：1行（120px）

### 3.3 拖拽操作

**移动小部件：**
1. 进入编辑模式
2. 鼠标悬停在小部件顶部，出现拖拽手柄
3. 按住拖拽手柄，移动到目标位置
4. 松开鼠标完成移动

**调整大小：**
1. 进入编辑模式
2. 鼠标悬停在小部件右下角
3. 出现缩放手柄后，拖拽调整大小

### 3.4 全屏模式

点击顶部工具栏的"全屏"按钮，进入全屏显示模式，按 `ESC` 键退出。

## 四、小部件管理

### 4.1 小部件类型一览

| 分类 | 小部件类型 | 功能说明 |
|------|-----------|---------|
| **基础组件** | 时钟 (clock) | 显示当前时间、日期、星期 |
| | 统计卡片 (stats) | 展示多个统计指标，支持趋势显示 |
| | 图表 (chart) | ECharts 图表展示（柱状图、折线图等） |
| | 快捷链接 (link) | 显示链接卡片列表 |
| | 新闻动态 (news) | 展示新闻资讯列表 |
| | 排行榜 (topList) | 显示排行榜数据 |
| | 搜索框 (search) | 搜索输入组件 |
| | 数据表格 (dataTable) | 表格展示和数据操作 |
| | 卡片网格 (cardGrid) | 多卡片网格布局 |
| | 自定义表单 (customForm) | 动态表单生成 |
| | 文本组件 (typography) | 文本/标题显示 |
| **导航组件** | 图标导航 (iconNav) | 图标形式的导航入口 |
| | 导航组 (navGroup) | 导航项分组展示 |
| | 页面切换器 (pageNavigator) | 页面快速切换 |
| **特殊组件** | 导航栏 (headerBar) | 仪表盘顶部标题栏 |
| | 微应用 (microApp) | 嵌入第三方微应用 |

### 4.2 添加小部件

**方式一：下拉菜单添加**
1. 点击顶部工具栏的"添加小部件"按钮
2. 在下拉菜单中选择小部件类型
3. 小部件自动添加到仪表盘底部
4. 拖拽到目标位置

**方式二：微应用市场**
1. 点击"添加小部件" → "微应用"
2. 打开微应用市场弹窗
3. 浏览并选择目标微应用
4. 点击添加到仪表盘

### 4.3 配置小部件

1. 点击小部件右上角的"设置"图标（齿轮）
2. 打开配置对话框
3. 根据需要修改配置项
4. 点击"确定"保存配置

**通用配置项：**

| 配置项 | 说明 |
|--------|------|
| 标题 | 小部件显示的标题文字 |
| 显示标题 | 开关控制是否显示标题栏 |
| 刷新间隔 | 自动刷新数据的时间间隔（秒） |
| 背景设置 | 支持纯色、渐变、图片背景 |

### 4.4 删除小部件

1. 进入编辑模式
2. 点击小部件右上角的"删除"图标（垃圾桶）
3. 确认删除

### 4.5 小部件分组

支持将多个小部件组织成一个分组：
1. 添加"分组容器"类型小部件
2. 配置分组标题、背景、边框样式
3. 在分组内部添加子小部件

## 五、浮动模块管理

### 5.1 什么是浮动模块

浮动模块是**独立于网格布局**的可拖拽窗口，适用于：
- 在线客服聊天窗口
- 系统通知中心
- 助手工具入口
- 微应用浮窗

### 5.2 浮动模块类型

| 类型 | 说明 |
|------|------|
| 聊天 (chat) | 在线客服/AI 助手对话 |
| 通知中心 (notification) | 消息通知展示 |
| 助手中心 (assistantHub) | 微应用快速入口 |
| 微应用 | 以浮窗形式展示的微应用 |

### 5.3 浮动模块操作

**添加浮动模块：**
1. 点击顶部工具栏的"添加浮动模块"按钮
2. 选择模块类型
3. 浮动模块出现在屏幕上

**移动位置：**
- 拖拽浮动模块的标题栏即可移动位置

**调整大小：**
- 拖拽浮动模块的边缘或角落调整尺寸

**折叠/展开：**
- 点击浮动模块的折叠按钮可最小化显示
- 再次点击展开按钮恢复原大小

**关闭浮动模块：**
- 点击浮动模块右上角的关闭按钮

### 5.4 浮动模块配置

右键点击浮动模块或点击设置图标，可配置：
- 模块标题
- 窗口大小限制
- 主题样式
- 行为设置（可拖拽、可缩放、可折叠等）

## 六、微应用集成

### 6.1 微应用概述

微应用是通过 **Wujie 微前端框架** 集成的第三方独立应用，可以嵌入到：
- Dashboard 小部件中
- 浮动模块中
- 全局模式（占满整个容器）

### 6.2 微应用市场

1. 点击"添加小部件" → "微应用"
2. 打开微应用市场弹窗
3. 左侧显示系统分类
4. 右侧显示对应的模块列表
5. 选择模块后点击添加

### 6.3 微应用配置页面

访问路径：`/micro-app-config`

功能模块：
- **系统管理**：创建/编辑/删除微应用系统分类
- **模块管理**：创建/编辑/删除具体的微应用模块
- **事件配置**：配置模块间的事件通信

### 6.4 微应用配置项

| 配置项 | 说明 |
|--------|------|
| 系统ID | 微应用所属系统的唯一标识 |
| 模块ID | 微应用模块的唯一标识 |
| 微应用URL | 微应用的访问地址 |
| 入口文件 | 微应用的入口 HTML 文件地址 |
| 图标 | 微应用在市场中显示的图标 |
| 描述 | 微应用的功能描述 |

### 6.5 微应用配置导入导出

在微应用配置页面：
- 点击"导出"按钮可下载 JSON 配置文件
- 点击"导入"按钮可上传配置文件批量导入

## 七、主题与个性化设置

### 7.1 主题模式切换

系统支持两种主题模式：
- **浅色模式 (Light)**：默认模式，适合日间使用
- **暗黑模式 (Dark)**：适合夜间或弱光环境

**切换方式：** 点击顶部工具栏的主题切换按钮

### 7.2 主题预设

系统内置多种主题预设：

| 预设名称 | 特点 |
|---------|------|
| Light | 标准浅色主题 |
| Dark | 标准暗黑主题 |
| Blue | 蓝色调主题 |
| Purple | 紫色调主题 |

### 7.3 主题自定义

点击主题自定义按钮，可调整：
- 主色调 (Primary Color)
- 成功色 (Success Color)
- 警告色 (Warning Color)
- 错误色 (Error Color)
- 圆角大小
- 间距设置

### 7.4 背景设置

小部件和仪表盘支持三种背景类型：
- **纯色背景**：选择单一颜色
- **渐变背景**：支持线性渐变和径向渐变
- **图片背景**：上传或输入图片地址

## 八、仪表盘发布与分享

### 8.1 发布流程

1. 完成仪表盘配置后，点击顶部"发布"按钮
2. 在弹窗中输入仪表盘标题
3. 点击"确定"完成发布
4. 系统返回发布成功提示和分享链接

### 8.2 发布列表管理

访问路径：`/publish-list`

功能：
- 查看所有已发布的仪表盘
- 搜索/分页查询
- 编辑：加载已发布配置到编辑器重新修改
- 预览：以只读模式查看
- 删除：移除已发布的仪表盘

### 8.3 预览模式

通过 `/preview/:id` 路径访问已发布的仪表盘：
- 只读显示，不可编辑
- 适合分享给最终用户查看
- 数据实时刷新

### 8.4 发布数据结构

发布时保存的内容包括：
- 所有小部件的类型和配置
- 小部件的位置和大小信息
- 浮动模块的配置
- 仪表盘背景设置

## 九、系统配置管理

### 9.1 配置文件位置

| 配置文件 | 位置 | 用途 |
|---------|------|------|
| 微应用配置 | `public/config/micro-apps.json` | 微应用系统和模块定义 |
| 应用配置 | `window.__APP_CONFIG__` | 生产环境 API 地址配置 |

### 9.2 本地存储说明

系统使用浏览器本地存储保存用户配置：

| 存储键 | 内容 |
|--------|------|
| `portal-engine-storage` | 仪表盘布局、小部件配置 |
| `themeMode` | 主题模式 (light/dark) |
| `themePreset` | 当前使用的主题预设 |
| `locale` | 语言设置 |

### 9.3 清除本地配置

如需重置用户配置：
1. 打开浏览器开发者工具 (F12)
2. 进入 Application → Local Storage
3. 找到对应的存储键并删除
4. 刷新页面

### 9.4 权限配置

用户权限通过后端 API 返回的 `userInfo.route` 数组控制：
- 只有在权限列表中的路由才允许访问
- 无权限访问的路由会跳转到 403 页面

## 十、常见问题排查

### 10.1 登录相关问题

**问题：登录后立即跳转回登录页**

排查步骤：
1. 检查 Cookie 是否正确设置（查看 YSTOKEN）
2. 检查后端登录接口返回是否正常
3. 清除浏览器缓存后重试

**问题：登录接口报错**

排查步骤：
1. 确认后端服务是否正常运行
2. 检查网络连接
3. 查看控制台错误信息

### 10.2 Dashboard 相关问题

**问题：Dashboard 显示空白**

排查步骤：
1. 检查控制台是否有错误信息
2. 检查用户是否有 Dashboard 路由权限
3. 尝试清除 localStorage 后刷新
4. 检查 API 接口是否正常响应

**问题：小部件无法拖拽**

排查步骤：
1. 确认是否处于编辑模式
2. 检查浏览器是否禁用了拖拽功能
3. 刷新页面重试

**问题：小部件配置不保存**

排查步骤：
1. 检查浏览器是否禁用了 localStorage
2. 检查存储空间是否已满
3. 查看控制台错误信息

### 10.3 微应用相关问题

**问题：微应用加载失败**

排查步骤：
1. 检查微应用 URL 是否可访问
2. 检查微应用入口文件是否存在
3. 查看控制台错误信息
4. 确认微应用支持被嵌入（无 X-Frame-Options 限制）

**问题：微应用显示空白**

排查步骤：
1. 检查微应用本身是否能独立访问
2. 确认微应用的跨域配置正确
3. 检查 Wujie 框架的生命周期钩子是否报错

### 10.4 性能相关问题

**问题：拖拽卡顿**

解决方案：
1. 减少 Dashboard 中的小部件数量
2. 关闭不必要的浮动模块
3. 检查是否有小部件持续刷新数据

**问题：页面加载慢**

解决方案：
1. 检查网络连接速度
2. 优化微应用的加载配置
3. 使用浏览器开发者工具分析性能瓶颈

### 10.5 浏览器兼容性

**支持的浏览器：**
- Chrome 80+（推荐）
- Firefox 75+
- Edge 80+
- Safari 13+

**不支持：**
- Internet Explorer（任何版本）
